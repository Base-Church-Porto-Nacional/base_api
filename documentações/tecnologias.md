## 5. Arquitetura Geral

O projeto utiliza uma arquitetura composta por uma aplicação
**Front-end**, uma **API Back-end**, um **banco de dados PostgreSQL** e uma
infraestrutura baseada em serviços de nuvem e containers.

### Front-end

O front-end será desenvolvido utilizando **Flutter**, permitindo a
construção da aplicação para diferentes plataformas, incluindo **Web,
Android e iOS**.

### Back-end

O back-end será desenvolvido em **Java**, utilizando o **Spring Boot**
para construção da API.

O **Maven** será responsável pelo gerenciamento das dependências e pelo
processo de build do projeto.

### Banco de Dados

O sistema utilizará o **PostgreSQL** como banco de dados relacional
principal.

### Infraestrutura

A infraestrutura utilizará **AWS** para hospedagem, **Docker** para
containerização, **Nginx** como servidor web e proxy reverso e
**Cloudflare** para gerenciamento de DNS e recursos de segurança.

O **GitHub** será utilizado para hospedagem dos repositórios e
gerenciamento do código-fonte.

## 6. Ferramentas de Desenvolvimento

Para o desenvolvimento e validação do sistema serão utilizadas ferramentas
como **Figma**, para criação dos protótipos e interfaces, e **Postman**,
para realização de testes nas APIs.
